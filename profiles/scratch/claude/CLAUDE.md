# scratch

Profile vacío para ir armando cosas a medida que lo uso.

## Tooling

- **cvm** — "Config Version Manager" para harnesses de agentes (tipo `nvm` pero para la config de tu agente): maneja perfiles de configuración a nivel usuario, switchea entre ellos al instante vía symlinks y permite volver a vanilla (`cvm off`); perfiles vacíos o linkeados a un repo git (`add`/`use`/`ls`/`pull`/`push`).
